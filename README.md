## 腾讯云对象存储带宽能有多少？三个上限要分开看

COS 的带宽没有单一数字，能查到的规格分布在三个层次上，混着看很容易得出错误结论。

**园区默认下行带宽**：官方文档的表述是“默认情况下，COS 单账号下的带宽规格存在上限”，具体数值按园区不同。文档里给出的案例是广州园区，默认下行带宽上限 15Gbps。控制台里带宽值如果带“未调整”标签，说明还是默认值。

**按存储量换算的免费读带宽**：中国大陆地域 10Gbps/PB，中国香港及境外地域 5Gbps/PB。这部分不额外收费，账单里自动减免，作用是把桶的读带宽上限抬上去。

**购买读带宽配额后的上限**：在默认规格基础上，对单个存储桶做桶级别的下行带宽提升。申请的目标规格要求是 10Gbps 的倍数，或者直接等于默认带宽上限。

顺带纠正一个流传很广的说法：不少资料写“COS 带宽没有具体上限，动态分配”。容量和对象数量确实不设限（同一 APPID 下存储桶数量上限 200 个，桶内对象和目录不限），但下行带宽有明确规格，只是规格可以花钱买。

## 免费读带宽怎么算：一条公式、两个取整陷阱

免费带宽的算法是：**max（前一日在线存储量 × 地域系数，园区默认带宽上限）**。取较大值，不是相加。

有三个细节会直接影响你算出来的数字：

1. **存储量按 PB 向下取整**。1800TB 换算成 PB 是 1.7578，向下取整为 1PB，只能按 1PB 换带宽。差一点点到 2PB 的时候，别提前按 2PB 做预算。
2. **只统计在线存储类型**。计进去的是标准存储、低频存储、智能分层存储；归档存储和深度归档存储不算。一个存了 5PB 归档数据的桶，在免费带宽换算上等于零。
3. **统计的是前一自然日的日均存储量**。今天的账单看昨天的量，扩容和清理都不会立刻反映到带宽额度上。

官方文档里的例子：广州园区的桶，日均在线存储量 20TB，不足 1PB，免费读带宽就是默认的 15Gbps。存储量涨到 2PB 以上，免费额度变成 20Gbps。

还有个前提：按存储量算出来的免费带宽，只有大于默认带宽上限时才起作用。存储量小的时候，你拿到的是默认上限，不会被压低。

## 读带宽配额多少钱：单价、结算规则与两个反直觉的地方

配额是后付费、按日结算，单价按地域分四档，中国大陆最便宜，圣保罗最贵。

| 法兰克福 | 25.80 |

每日费用的公式长这样：

**读带宽配额费用（每日）=（日均目标带宽额度 − 免费带宽额度）× 单价**

其中日均目标带宽额度 = 当日每 5 分钟目标带宽额度之和 ÷ 288。一天 288 个采样点，统计区间是 00:00:00 到 23:59:59。

反直觉的地方一：**按购买规格计费，跟你实际跑了多少无关**。买了 50Gbps 的目标规格，实际只跑到 20Gbps，计费还是按 50Gbps 减免费额度来算。文档原话是“购买后计量将会使用购买规格进行结算，与提升后的实际带宽使用量无关”。

反直觉的地方二：**免费额度可能把账单抹平**。看官方给的案例：北京园区，默认 15Gbps，目标提到 50Gbps，9 月 1 日日均在线存储量 3PB，免费额度 = max(3×10, 15) = 30Gbps，当天费用 =（50−30）× 14.333 = 286.66 元。存储量涨到 6PB 之后，免费额度 = 60Gbps，已经超过 50Gbps 的目标规格，费用变成 0 元。

也就是说，存储量在涨的桶，配额费用会自己往下掉；存储量长期不动的桶，这笔钱就是固定的。

## 带宽上限不等于实测速度

带宽上限只是天花板。实际能跑多快，还取决于客户端并发数、单连接吞吐、跨地域链路质量，以及请求本身的特征。

几个实际影响：

- 单线程下载通常吃不满桶的带宽，多线程或多个客户端并发才容易压满。
- 同地域的 COS 和云服务器之间走内网，不产生外网下行流量费用；跨地域内网访问会产生跨地域流量费用。
- 静态资源分发走 CDN 之后，回源压力落在源站上的部分会小很多，这时候瓶颈往往在 CDN 侧而不在 COS。
- 大量小文件的高频读取，费用大头通常在请求次数上，带宽反而不是限制项。请求费用按发送到 COS 的请求指令次数计算，包含用户请求次数和后端请求次数。

## 该不该买读带宽配额：先确认瓶颈，再算这笔钱

配额解决的是“桶的下行带宽上限不够”，解决不了“客户端下载慢”或“公网链路抖动”。先定位瓶颈，再决定要不要花这笔钱。

值得买的情况：

- 大数据计算、AI 训练、内网文件分发，读操作密集，且有明确的作业完成时间要求。
- 桶的在线存储量不大，免费额度上不去，但业务确实需要更高的下行带宽。
- 已经用 CDN 分流，源站仍然是瓶颈。

不用买的情况：

- 流量主要来自公网终端用户下载，CDN 是更直接的解法。
- 桶里绝大部分是归档数据，这些数据不计入免费带宽换算。偶尔取回一次，按数据取回费用算通常比长期维持配额便宜。
- 只是单台机器下载慢，先查并发数、链路和 DNS。

## 常见问题

**COS 的带宽是无限的吗？**

存储容量和对象数量不设上限，但下行带宽有默认规格，超出部分要通过读带宽配额提升。所谓“无限”只适用于容量。

**免费带宽额度是每个月发一次吗？**

免费带宽按日核算，在账单层面自动减免：每天按前一自然日的在线存储量算出免费带宽，再从当天的配额费用里扣掉。它不形成一个可以单独查看、单独领取的额度包。

**买了配额但没用满，还收费吗？**

收。计费按你购买的规格算，不看实际跑量。唯一能减少费用的是存储量上涨带来的免费额度提升。

**提升带宽要多久生效？**

提交购买、扩容、缩容申请后，平台会在 24 小时内完成带宽配额调整。加急需单独联系。

**带宽费用包含流量费吗？**

不包含。读带宽配额费用只负责把桶的带宽上限提到指定值，实际产生的下行流量按下行流量计费项单独收取。COS 也不支持按带宽峰值计费，只按流量数值计费。
